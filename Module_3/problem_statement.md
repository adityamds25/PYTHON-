Module 3: Password Validation and Strength

Problem Statement

Improve the Random Password Generator by adding password-length validation, checking the required character types, and evaluating password strength.

The program should reject invalid password lengths, ensure that every selected character type is included in the generated password, and provide a simple password-strength estimate.

Objectives

1. Validate the password length.
2. Require at least one selected character type.
3. Ensure that every selected character type appears in the generated password.
4. Generate the password using secure random selection.
5. Estimate password strength based on its length and character diversity.

Expected Outcome

The program generates a valid password that satisfies the user’s selected character requirements and displays a basic strength estimate.
