Module 2: Customizable Random Password Generator

Problem Statement

Develop a customizable Random Password Generator using Python. The program should ask the user for the required password length and allow the user to select the character types to include in the password.

The available character types are uppercase letters, lowercase letters, numbers, and special characters. The program should generate a random password using the character types selected by the user.

Objectives

1. Accept the required password length from the user.
2. Allow the user to select character types.
3. Generate a password according to the user’s choices.
4. Use secure random selection to generate the password.
5. Display an appropriate message if no character type is selected.

Expected Outcome

The program generates a password of the requested length using only the selected character types.
