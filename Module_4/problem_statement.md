Module 4: Final Integration and Testing

Problem Statement

Integrate the features developed in the previous modules into one complete Random Password Generator using Python. The final program should support password customization, input validation, required character-type checking, secure password generation, and a basic strength estimate.

The complete program must be tested using different inputs to verify that it works correctly.

Objectives

1. Combine the features of Modules 1, 2, and 3.
2. Accept and validate the password length.
3. Allow the user to select character types.
4. Generate passwords that satisfy the selected requirements.
5. Display the password and its estimated strength.
6. Test valid inputs, invalid inputs, and different character selections.

Expected Outcome

A complete and tested Random Password Generator that combines all project features into one working Python program.
